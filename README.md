# Naing Myo Htet — Portfolio

Personal portfolio for Naing Myo Htet, a Computer Science and Engineering student. It presents selected projects, skills, education, and contact information, with a downloadable CV.

## Built with

- React
- TypeScript
- Vite
- Lucide React

The portfolio was built with **Pockraft**.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
